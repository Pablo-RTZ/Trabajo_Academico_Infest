# README

## Resumen para uso

Antes de editar nada

```bash
git pull
```

Al terminar de trabajar

```bash
git add . 
git commit -m "Describir los cambios hechos"
git push
```

Estos comandos siempre teniendo como directorio de trabajo la carpeta principal del repo

(`cd Desktop/Universidad/loquesea/Trabajo_Academico_Infest`)
